## 🛠️ Understanding Kubernetes Pod Lifecycle (19.02.2026)

Kubernetes Pods have a defined lifecycle that includes various phases from Pending to Running and Terminated. Understanding these phases helps in managing application deployments effectively.

```yaml
apiVersion: v1
kind: Pod
metadata:
  name: example-pod
spec:
  containers:
  - name: example-container
    image: nginx
```
