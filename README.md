## 🛠️ Refactoring: The Art of Clean Code (16.02.2026)

Refactoring is the process of restructuring existing code without changing its external behavior. It improves code readability and reduces complexity, making it easier to maintain.

```python
def calculate_area(radius):
    return 3.14 * radius ** 2
```
