## 🛠️ Understanding Kubernetes Networking (12.02.2026)

Kubernetes networking allows seamless communication between pods, services, and external traffic. Key components include Services, Network Policies, and CNI plugins.

```yaml
apiVersion: v1
kind: Service
metadata:
  name: my-service
spec:
  selector:
    app: my-app
  ports:
    - protocol: TCP
      port: 80
      targetPort: 8080
```
